# python-security-tools
# 🛡️ Proyectos de Ciberseguridad en Python

Este repositorio reúne tres proyectos simples pero prácticos en **Python**, orientados a la ciberseguridad.  
Son ideales para aprender conceptos básicos de seguridad informática y mostrar habilidades en programación.

---

## 📂 Contenido

1. **Generador de Contraseñas (`password_generator.py`)**  
   - Genera contraseñas seguras y aleatorias.  
   - Permite configurar longitud y tipo de caracteres (mayúsculas, minúsculas, números, símbolos).  

2. **Escáner de Puertos (`port_scanner.py`)**  
   - Escanea puertos abiertos en una dirección IP o dominio.  
   - Útil para pruebas de seguridad y reconocimiento básico de servicios.  

3. **Hash Cracker (`hash_cracker.py`)**  
   - Intenta descifrar hashes comunes (MD5, SHA1, SHA256) mediante fuerza bruta o diccionario.  
   - Ejemplo educativo sobre cómo funcionan los ataques de cracking.
